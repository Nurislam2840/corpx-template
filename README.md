# CorpX — Corporate Website Template

Modern, responsive corporate business template built with pure HTML, CSS, and JavaScript.

## ✨ Features

- 🎨 Premium Indigo + Cyan gradient design
- 📱 Fully responsive (mobile, tablet, desktop)
- ⚡ Lightning fast (no frameworks)
- 🔍 SEO optimized (meta tags, Open Graph, Schema.org)
- ♿ Accessible (ARIA labels, semantic HTML)
- 🎭 Smooth scroll animations
- 🧩 Modular CSS architecture

## 📄 Pages

- `index.html` — Home
- `about.html` — About Us
- `services.html` — Services
- `portfolio.html` — Portfolio
- `blog.html` — Blog
- `contact.html` — Contact
